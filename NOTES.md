# Development notes

**For agents and maintainers, not for users.** Findings and reasoning that would
otherwise clutter the walkthrough. Nothing here is needed to *use* these
examples — for that, see the README and
[`docs/WALKTHROUGH.md`](docs/WALKTHROUGH.md).

Put development findings here rather than in the walkthrough. The walkthrough is
a verified transcript: every command in it was run against hardware, and its
value is that a reader can follow it exactly. Notes about how it was arrived at
belong here, and changes to it should be re-run rather than edited.
